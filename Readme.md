#  DVD Rental Analytics | Power BI Project

##  Project Overview

This project focuses on analyzing a DVD rental business using SQL and Microsoft Power BI. The objective was to transform raw rental data into an interactive dashboard that helps analyze business performance, customer behavior, rental activity, and revenue.

The project demonstrates my skills in **SQL, Power BI, DAX, Data Modeling, Data Analysis, and Data Visualization**.

---

##  Business Objectives

The main objectives of this project were to:

* Analyze overall rental performance
* Track total revenue generated by the business
* Monitor active, returned, and overdue rentals
* Analyze customer activity and registration trends
* Identify top customers based on revenue
* Compare rental performance across stores
* Analyze film categories and rental patterns
* Build an interactive Power BI dashboard for business insights

##  Key DAX Measures

Some of the DAX measures created for this project include:

```DAX
Active Rentals =
CALCULATE(
    COUNTROWS(rental),
    FILTER(
        rental,
        ISBLANK(rental[return_date])
    )
)
```

Other measures include:

* Returned Rentals
* Overdue Rentals
* Active Customers
* Total Categories of Films
* Revenue per Customer
* Rentals per Store
* Customers This Month
* Top 10 Customers by Revenue
* Customer Registration Trend
